### 1. 타이블에 ### 3개 붙일 것
	#### 1.1 소스트리 커밋시 보이는 제목과 일치 시켰을 때 적당한 크기임.
### 2. 수정사항 1), 2), 3).. 같은 스타일로 소제목 구분, 
	#### 2.1 끝에 공백 2개 넣어줄 것(줄바꿈, 단락 구분을 위해서)
	#### 2.2 그냥 enter키로 줄을 바꾸면 들여쓰기가 맞게 않게 됨.
### 3. 소제목 에서는 내용마다 +, *, -  총 3가지의 기호 사용 가능 (동일한 출력)
	#### 3.1 소스코드 등과 같이 강조하고 싶을 때 블럭인용문자 '>', '>>' 사용함. (BlockQuote 사용하기)
	#### 3.2 탭키를 사용하여 코드블럭 사용할 때 주의사항
		 주의 : 코드 블럭 시키고 싶은 내용 앞뒤로 enter 해줘야함
	#### 3.2 들여쓰기 단계는 
	* 1단계
		- 2단계
			+ 3단계
	   		+ 4단계
### 4. 기타
	#### 4.1 변경점 간 내용 구분 기호는 '--- ... ---' 80 개로 한다.

### V1.00.99.52 20240419 자동위치모드 개선, 홈밍 가감속 개선(DCT KNS대응), BHCHUN

1) 자동위치모드 기능 동작 수정 요청  
	위치완료 상태에서 자동위치모드로 변경시 파렛이 이동하지 않는 현상
	- 원인: 위치완료 상태(13)에서 바로 자동위치모드의 위치완료로 진행함.
	- 동작 개선:  
	자동위치모드가 켜져있다면 항상 속도이동하여 현재 파렛을 배출하도록 수정함.
	- 동작 수정(2가지 CASE):  
	VP13_01 위치완료(13)->자동위치모드 준비(50)  
	VP02_50 속도이동(02)->자동위치준비(50)
2) Homing Mode 수정  
	홈밍트리거 이후 속도 가감속이 발생하지 않는 현상 수정
	- LMS_STATUS 추가  
		- LMS_HOME_OFFSET_INIT  
		- LMS_HOME_OFFSET_RUN
			* 홈트리거를 만난 후 Offset위치
		+ 5mm (감속거리)이하이면 바로 위치 완료(28)로 진행함.
	> 소스 변경점 1
	
		LMS_IOMapping_P_COM(ax);  
		LMS_IOMapping_V_COM(ax);
	>> 각각의 함수를 LMS control 루프에서 동작하도록 변경함.

	> Pseudo Code 예시 2 (코드블럭 스타일 사용시)
	>> 모듈화된 코드

		void PROCESS_Homing_SwitchingRule(uI16 ax);      //20241211 홈밍 스위칭룰
		void PROCESS_SyncMotion_SwitchingRule1(uI16 ax); //20241211 동시이동 스위칭룰1
	- CCW 방향(HomingEntry_direction=-1)  
	조건식1 (5mm이내, A구역) : 위치명령>(트리거 - 5mm)  
	조건식2 (5mm이내, B구역) : 위치명령-(트리거 - 5mm)
