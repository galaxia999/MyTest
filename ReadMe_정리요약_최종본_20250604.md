## DCT Encoder SPEC
-------------------------------------------------------------------------------
### 1) DCT 인코더 데이터 포맷(Basic)
	DF0/1 : Master Enc.
	DF2   : Proximity Sensor Status
	DF3   : Hall Sensor Status
	DF4/5 : Slave Enc.
	DF6   : RFID tag
	DF7   : Extended Proximity Sensor Status

### 2) 고정도 인코더 사용시 프로토콜 간단 요약(Advanced)
	VALID                      DF3.7, DF7.7
	Position offset            DF4, DF5
	RFID                       DF6
	Extended Proximity Sensor  DF7

### 3) 인코더 알람비트
	- E.106, 인코더 통신 4회 이상 오류 발생시 알람 처리 (표준 FW는 3회임)
	알람 reg에 비트 정의: D4:TIMOT, D3:SFOME, D2:FOME, D1:CRCE, D0:CONTE
	if (Reg5810.RxDATA5 & 0x1F00) { // D4:TIMOT, D3:SFOME, D2:FOME, D1:CRCE, D0:CONTE  
 
### 4) 확장 근접센서(DHE, DF3, DF7) I/O 4점 지원
	- 용어: Extended Proximity Sensor, Ext PHS
	- T-format DF3, DF7로 전송
	- DCT 인코더A/B는 각각 외부 2점의 IO 입력센서값을 받는다.
	- DCT 인코더A : DF3 bit6/5, 0x2A9A bit1/0
	- DCT 인코더B : DF7 bit6/5, 0x2A9A bit9/8
	- 0x2A9A PDO 맵핑에 추가.
	- 확장센서와 모든 홀신호는 오브젝트의 고정자리에 맵핑되도록 사양 결정 (DCT요청사항)
	- Valid 신호와 상관없이 항상 업데이트됨.

### 인코더 DF3, DF7에서 수신되는 값을 표시하는 오브젝트
	- 0x2A9A Extended Proximity Sensor, Ext PHS
	- T-format DF3, DF7로 수신
		- DCT 인코더A/B는 각각 외부 2점의 IO 입력센서값을 받는다.
		- DCT 인코더A : DF3 bit 5/6, 0x2A9A bit 0,1에 대응 
		- DCT 인코더B : DF7 bit 5/6, 0x2A9A bit 8,9에 대응
		- 0x2A9A 오브젝트는 DF3/DF7 전체값를 표시한다
	- 확장센서와 모든 홀신호는 오브젝트의 고정자리에 맵핑되도록 사양 결정
	- Valid 신호와 상관없이 항상 업데이트됨
	
	0x2A9A/0x3A9A/0x4A9A LMMT_Extended Proximity Sensor (하위바이트: Enc A, 상위바이트: Enc B 대응)

## MOSI/MISO 신호 동작 SPEC
-------------------------------------------------------------------------------
### 1) 필터링 처리 방식
	- D7 vs D8 비교해서 차이가 있음
	- MOSI.2 필터링 처리함. 동기화하지 않음 like D7
	- MOSI.3 LMS 제어부와 동기화. like D7
	- MOSI.5 LMS 제어부와 동기화. like D7
	- MOSI.7 LMS 제어부와 동기화. like D7
	- MOSI.13 LMS 제어부와 동기화. like D7

### 2) 개별 신호 동작
	1) MISO.1 TGON  
		ON조건: 속도명령이 ft-2.19보다 큰 경우
		OFF조건: 다음의 조건들 중 하나라도 만족하는 경우임.
		1)PCOM ON일때
		2)속도준비단계(0)
		3)속도정지단계(3)이고 속도명령이 0인 경우
		4)위치준비단계(10)
		5)홈밍준비단계(20)
	2) MISO.7 P-COM  
		Trigger(LMS Trigger Flag)신호가 ON이고 위치에러가 ft-3.18보다 같거나 작을때 ON 됨
		(Trigger신호는 속도/위치일때 항상 ON이고 홈밍시작할때 OFF되고 홀센서 트리거될때 ON 된다)
	3) MISO.15 통신 비상정지 상태임을 알리는 비트 추가.

        0x606C0020	Velocity Actual Value
        0x60770010	Torque Actual Value
        0x603F0010	Error Code

        0x663B0020	LMMT_RFID_DF6

        0x66A80020	SyncEB PalletInCnt
        
### 2) A/B/C축 슬롯에 대한 ModuleIdent 개별 할당
  	Axis-A : x619800
  	Axis-B : x719800
  	Axis-C : x819800
  	
### 3) PDO 업데이트 방식 : DC sync 인터럽트에서 동작
	- 검색어: PDO_UPDATE_ISR
	
### 4) EtherCAT 동작 모드(0x6060, Modes of operation)와의 관계
	- D7 : master scan시 기본값 CSP(8)모드
	- D8 : master scan시 기본값 NN(-13)모드
		CSP(8): LMS 운전 불가능, 빌트인에 "F" 표시
		CSV(9): LMS 운전 불가능, 빌트인에 "S" 표시
		CSV(-13): LMS 운전 가능, 빌트인에 "nn" 표시
	- 다른 동작모드(CST/HM/PP)는 ft-0.0값이 변경되고 지원하지 않음. 
	- LMS 설정 오브젝트가 맞지 않는 경우 알람 발생, E.207
	
	** A축의 0x6060=-13이고 ft-0.0=13일때 A/B/C모든 축이 LMS 동작모드로 자동설정된다.
		A축 기준으로 LMS 동작모드를 설정해야 정상적으로 동작한다. 
		B축/C축을 개별적으로 설정하더라도 A축을 따라감 
	** 0x6060: -13 일때 LMMT모드로 자동 동작하도록 xml파일 수정
		InitCmd 에 HexBinary 타입으로 F3(0xF3= -13dec)
		MMCE로 스캔시 0x6060은 USINT값으로 243dec 으로 등록됨.
		
### 5) FOE를 이용한 FW 다운로드시 빌트인 표시 개선
	FOE로 FW업데이트 진행되었음을 알려주는 상태 플래그를 도입하여 빌트인 표시되는 메시지의 동작을 개선함.
	- 다운로드 시작시 전면부 세그멘트상에 "GO", 완료시 "done", 다운로드 에러 발생시 "Error"
	- FOE를 이용한 다운로드시 자동 드라이브 리셋이 되지 않으므로 새로운 버전을 적용할려면 반드시 전원 on/off를 해야 한다.
	- FW 업데이트가 한번이라도 완료된 상태이고 전원을 끄지 않았다면 "done" 표시는 유지된다.
	- FOE로 FW 업데이트 되었음을 알려주는 상태 플래그, MB_firmwareUpdatedFlag = FALSE;
	- FW 업데이트가 한번이라도 완료된 상태이고 전원을 끄지 않았다면 "done" 표시는 계속 유지된다. (사용자에게 알려주기 위함)

### 6) PDO 맵핑 지원을 위한 미러링 오브젝트 추가 (D8 전용)
	- 사용 영역
	      미러 오브젝트 [0x6000 ~ 0x60FF] : 파리미터 변수 변수 256개 맵핑 (각축)
	      미러 오브젝트 [0x6600 ~ 0x66FF] : 모니터링 변수 256개 맵핑 (각축)
	   0x600A ~ 0x6018 각축
	   0x663B ~ 0x663D, 0x6696 ~ 0x669A, 0x66A1 ~ 0x66B0 각축

## LMMT 부하율 SPEC
-------------------------------------------------------------------------------   
### 1) 평균부하율 계산
	- D7, D8_M 공통, 서보 기본 기능
	- 전류값을 사용하여 주어진 시간 동안의 평균값을 계산함.
	- ft4.23 Current Feedback Squared Integral Interval, 단위 [ms]
	- MDM 44 0x2A2C Current RMS     측정시간 설정시 동작함, 
	- MDM 45 0x2A2D Current RMS Max 0x2A2C의 최대값
  
### 2) LMS용 이동평균 부하율 시간 설정 기능
	- D7, D8_M 공통
	- 전류값으로 계산된 평균 부하율과 이에 대해 임의의 시간 동안의 이동 평균값
	- Valid 센서 ON/OFF 구간을 모두 포함한다.
	- D7 : ft-1.55 0x2137 LMMT_Current Load Moving Avg Time Setting, 0(default), 0~99999, 단위:sec
	- D8 : ft-3.44 0x232C Axis-A LMMT_Current Load Moving Avg Time Setting, 0(default), 0~99999, 단위:sec
	- MDM 44 0x2A96	LMS Motor Utilization(RMS)        : 0x2A2C와 동일함, 토크 순시값
	- MDM 45 0x2A97	LMS Motor Moving Utilization(RMS) : 0x2A2C에 대한 이동 평균값

### 3) 부하율 관련 단위
	- 토크 부하율, 0x6077 단위 재확인
		CSD7 BNM : 0.001[Amps] (기존 장비의 호환성을 위해 수정 못함)  
		D8, D8_M : 0.1[%] (백분율 단위)
	 > 예시: 
	 	전류 부하율 단위 (CSD7 기준)
		RSware Scope의 전류피드백 단위는 암페어임
		Torque Actual Value, 0x6077 값은 0.001 [Amps] 단위
		Motor 정격전류 2.4A 일때 0.074mA 값은  0.074*100/2.4 = 3.08 %
	- 속도피드백, 0x606C 단위 변경  
		CSD7 BNM : [pps]  
		D8_M : [mm/s] , 속도명령 파라메터 단위와 피드백을 맞추기 위함

## 파렛 SPEC
-------------------------------------------------------------------------------
### 1) PalletOffset 저장공간 600개 정의
	- ASCII 명령어 추가 (ERD, EWR)
	1) ERD300*  : 300번 배열 저장장소 읽기
	2) EWR300*  : 전체 저장(save), 플래쉬에 저장하기
	3) EWR300$  : 전체 로딩(load), 플래쉬에 저장된 값 읽기
	4) EWR300!  : default값으로 램저장장소 설정
	4) EWR300@  : all 0's, 테이블 0으로 초기화 하기
	5) EWR3004-1234  : 300번 배열, index 4번 위치에 -1234 값 쓰기
		EWR 한번에 여러개 쓰기하는 기능 추가
		EWR300% V1 & V2 & V3 & V4 & V5 & V6
	6) ERD3004  : 300번 배열, index 4번 위치 값 읽기.

### 2) ID 입력받아서 오프셋을 출력하는 기능
	- 300번지에 uuid 12345678 쓰기
		#EWR300%12345678&-22222222&-33333333&-44444444&-55555555&-666666666
	- uuid 12345678로 등록된 배열과 오프셋값 가져오기
		#ERD!12345678
		응답: [uuid][배열][v1][v2][v3][v4][v5][v6]
		$ERD12345678&300&12345678&-22222222&-33333333&-44444444&-55555555&-666666666
	> 쓰기 예시
		파렛1 설정 (Table 1, ID: 1111, CW offset:100, CCW_offset:-200)
		파렛2 설정 (Table 2, ID: 2222, CW offset:300, CCW_offset:-500)
		#EWR001%1111&0&100&-200&0&0
		#EWR002%2222&0&300&-500&0&0

		역방향(DIR=-1): 현재 위치값은 양간오차 절대값을 보정(+)한 값이므로 빼하고 더하는 방식으로 보정함.

## 파렛 오프셋 적용 SPEC
-------------------------------------------------------------------------------
1) 파렛 오프셋 보상 기능 로직
	- DCT장비 사용시 적용.
	- 이력: 진입 후 Valid A ON 될 때 적용되는 인코더 오프셋값이 인코더 전환 후 전환된 인코더의 정보가 사용되는 현상
	- 변경: 진입 후 Valid A&B 되는 시점에 적용되는 오프셋은 이전 인코더 기준으로 적용됨.  
	> 예시:  
	(EncA보드 ID:3, EncB보드 ID:5 로 가정하고 설명함)  
	
		1) polarity : Normal일때
			1-1)정방향 이동
				ID 3일때는 EncA 오프셋만 적용(계속 업데이트됨)

### 3-1) 외부 IO입력에 의한 HW 비상정지 기능 설명
	서보의 외부 입력 포트에 신호를 인가하여 직접 비상정지 운전모드로 진입하여 캐리어를 안전하게 정지시키는 기능입니다.
	- 비상정지용 외부 입력 하드웨어 : 외부 입력 INPUT 1 고정(I/O 5 pin)
	비상정지 외부 입력 기능이 활성화되면 속도 감속값 (0x2207 Deceleration)의 설정값으로 감속정지하고 1초 대기후에 서보 오프되고 알람 발생합니다. 기능 비활성화시에는 아무 동작도 하지 않습니다.
	
	RSware Drive->Auxiliary Function Selection1
	- ft-0.05 D3 Emergency Stop Input [disable/enable], 비상정지 외부 입력 기능 활성화
	RSware Drive->Group->Group 2
	- ft-2.07 Deceleration, 비상정지 감속도값, [m/s^2]
	- 개선 내용
		감속 속도 시작은 속도명령을 기준으로 한다. (현재 속도를 적용하면 리플이 많아서 가감속될 수 있음)
		감속값(ft-2.07)이 로터리모터 기준(rev/s^2)에서 리니어 단위(mm/s^2)로 적용되도록 수정함.
		기존에는 단위는 m/s^2인데 기본값이 로터리모터 단위로 41.667 rev/s^2로 크게 되어 있었다.
		default 감속도값=41.667[m/s^2] 단위일 때 정지시간은 대략 ~20ms(at 0.4 m/s)이내 빠른 감속으로 정지하였다.
		
		파렛 정지 속도 판단 수식을 수정하여 감속시간이 정확하게 나오도록 개선함.
			- 구동속도 0.2 [m/s], 감속도 0.2 [m/s^2] 적용시 감속시간 1[sec]로 정확하게 계산됨.
			- 0.4 [m/s^2] 적용시 감속시간 = 속도/감속도 = 0.2[m/s]/0.4[m/s^2] = 0.5[sec]
		속도0 정지 명령 판단 기준: 0.001mm/s 이하
		
	적용되는 운전모드 확대
	- 개선전: 속도/위치/홈밍 모드에서만 비상정지 동작
	- 개선후: 속도/위치/홈밍/스텝/자동위치/동시이동 등 비상정지 모드외 상시 동작되도록 수정
		비상정지 해제하는 방법
		비상정지 대기상태에서 비상정지 명령을 해제하는 방법은 MOSI bit 4 (Alarm reset) 을 1로 설정하여 MISO bit15(0x8000) 가 0으로 리셋된 것을 확인 후 다시 0으로 원복하면 된다.

## 자동위치 모드(VP) SPEC
-------------------------------------------------------------------------------       
### 1) 자동 속도/위치 모드 동작 사양
	1) MOSI bit8 VP flag 정의
	   - 6ms 필터 처리
	   1일때 속도운전으로 배출시키면 자동으로 속도위치대기(50)로 천이함.
	   0일때 속도운전으로 배출시키면 속도대기(0)로 천이함(기존 동작임)
	2) 속도런(2)상태에서 배출시 VP enable이면 속도위치대기(50)로 천이함. 위치대기(10-11-12-13)과 유사하다.
	3) VP disable이면 속도대기(0) 혹은 위치대기(10)로 천이함.
	4) VP_POS(53) 에서 속도이동으로 빠져나오는 방법
		MOSI bit8 ON->OFF->ON
		속도이동으로 이동중 속도런(2)상태에서 파렛을 빠져나올때 MOSI bit8 ON이면 VP 대기(50)으로 천이함.
		VP대기(50)에서 MOSI bit8이 OFF되면 속도 or 위치 모드로 이동한다. (대부분 속도기동상태이므로 속도이동함)
	
### 2) 파렛 1개, 서보1대로 동작 확인하는 방법 (예시)
	1) 파렛을 코일 위에 위치시키고 서보온 명령을 전송한다. MOSI=0x01
	2) 위치 자동전환 비트(MOSI.8)를 켜고 속도 이동하여 진입방향(왼쪽, 역방향)으로 배출시킨다.
		(파렛이 코일밖으로 빠져나오도록 수동으로 밀어준다.)
		>>MOSI=0x010D
	3) LMS_STATUS 상태가 위치자동모드 대기상태(50)임을 확인한다.
	4) 서보의 위치운전 방향을 정방향을 바꾼다. MOSI=0x0105
	5) 수동으로 파렛을 코일로 진입시킨다. 그러면 파렛은 티칭된 위치에 정지한다.
		<<LMS_STATUS (53)
	6) 왼쪽으로 배출하고 다음에 진입하는 파렛을 정위치 시킬려면 ON되어 있는 MOSI.8을 OFF->ON 을 하면 위의 상태를 반복하게 된다.
		MOSI.8이 OFF되는 시점에 속도기동되고 속도기동 배출 후 MOSI bit8이 ON이 되어 있어야 위치자동모드로 진입한다.
		트리거펄스 형태로 주어야 하며 파렛이 Open상태가 되기전에 ON을 해주어야 한다.
	7) MOSI.8을 OFF 시키거나 기동명령을 off시키면 일반적인 속도 혹은 위치운전으로 동작한다.

### 3) 동시이동 파렛 카운팅에 따른 제어 모드 동작
	파렛이 외부에서 모듈내로 진입한 후 속도이동으로 배출해야 하는 파렛의 카운팅(갯수) 값을 설정한다.
	- 진입하는 파렛에 대해 해당 모듈내에서 위치 정지시키는 경우 0 으로 입력한다.
	- 첫번째 진입 파렛을 속도이동으로 배출하고 두번째 파렛을 위치정지시키는 경우 1 으로 입력한다.
	- 첫번째,두번째 진입 파렛을 속도이동으로 배출하고 세번째 파렛을 위치정지시키는 경우 2 으로 입력한다.
	
	동작 시나리오
	- 파렛 카운팅 상태값이 파렛 카운팅 설정값보다 큰 경우 위치 모드로 전환
	- 그렇지 않은 경우 속도 모드 유지.
	예시 1)
		파렛 카운팅값이 0 인 경우 파렛 카운팅 상태값(1) > 파렛 카운팅값(0) 조건은 TRUE 이므로 위치모드 전환
	예시 2)
		파렛 카운팅값이 1 인 경우 파렛 카운팅 상태값(1) > 파렛 카운팅값(1) 조건은 FALSE 이므로 속도모드 유지
		다음 파렛이 진입하면 파렛 카운팅 상태값(2) > 파렛 카운팅값(1) 조건은 TRUE 이므로 위치모드 전환
	예시 3)
		파렛 카운팅값이 2 인 경우 파렛 카운팅 상태값(1) > 파렛 카운팅값(2) 조건은 FALSE 이므로 속도모드 유지
		다음 파렛이 진입하면 파렛 카운팅 상태값(2) > 파렛 카운팅값(2) 조건은 FALSE 이므로 속도모드 유지
		그 다음 파렛이 진입하면 파렛 카운팅 상태값(3) > 파렛 카운팅값(2) 조건은 TRUE 이므로 위치모드 전환

## 동시이동 인코더 홀센서의 트리거 신호 SPEC
-------------------------------------------------------------------------------
### 트리거 신호 정의 :  
	인코더 Valid 신호가 rising에서 ON되고 EA/EB VALID 값이 변경되면 OFF 된다.
	- Sync_Trigger_EA : 새 파렛이 EA 진입시 ON 되고 VALID 3 되면 OFF됨
	- Sync_Trigger_EB : 새 파렛이 EB 진입시 ON 되고 VALID 3 되면 OFF됨

### 트리거 신호와 연동된 FW 내부 플래그 정의 :
	1) 속도피드백 유지시간과 2파렛 진입시 현재 위치값 초기화 조건에 사용함.
	2) 위치모드 정지 후 동시이동 모드로 변경시 위치티칭값이 변경된 경우 위치이동 가능하도록 하는 플래그
	- 위치티칭값 변경 있는 경우 NEW PALLET ON 설정하여 바로 위치정지 가능하도록 함.(10->60->61->63)
	- NEW_PALLET 신호는 Valid ON 동안 유지한다. 그렇지 않으며 OFF 된다.
		SYNC_EA_NEW_PALLET : 인코더A Valid ON될때 ON, Open시 OFF된다.
		SYNC_EB_NEW_PALLET : 인코더B Valid ON될때 ON, Open시 OFF된다.
		* ON 조건: 
			1)EA or EB Valid 신호가 ON 될 때
			2)위치모드에서 위치정지 후 위치티칭값 변경시 ON, 항상 위치이동이 가능하도록 하기 위해서.
				등속구간에 감속정지하기 위한 판단 조건으로 사용함.
				(중요) MOSI.9 계속 ON인 동안 위치/스텝이동 가능하도록 처리하리하기 위한 용도.
		* OFF조건: 
			1)동시모드 진입시 항상 OFF시킴
			2)동시모드 탈출시 항상 OFF시킴(미구현상태)

	원인:	
	- PDO로 위치값(제1/2 위치값) 변경시 목표위치(target position)값은 변경되었으나 제어루프에서 목표위치 변경되었음을 인식 못함.
	이로 인해 제어루프의 STATUS가 변경되지 않았고 이 상태에서 목표위치(target position) 변경(위치에러 발생)으로 속도명령이 자동출력되었습니다.
	- FW에서 PDO로 동작시 현재값과 이전값을 비교하여 New 위치를 Old 위치값으로 업데이트하는 부분이 문제가 됨.	
	PDO에서 old 위치값이 업데이트가 되고 LMS control이 실행될 때는 조건문이 발생하지 않아서						
	결과적으로 현재 상태(13)를 유지하게 되었고 목표위치는 변경되었기 때문에 속도명령이 발생하였다.

	- FW 버그 수정:
	위치값은 이더캣 통신주기로 PDO/SDO를 통해서 업데이트만 되고 위치값 변경 유무는 LMS Control 루프에서만 검사하도록 수정함.
	위치명령의 변경 여부를 확인하는 코드를 통합함.
	영향받는 STATUS:       
		LMS_POS_POS: // 13
		LMS_VP_POS:  // 53
		LMS_SM_POS:  // 63
	변경전:
		Update_TargetPosition_And_StatusChanging(0);
		lms_pos_dir = LMS_DIR_VALUE;
		Update_PositionOld_PositionNegative(0);
	변경후:
		Update_TargetPosition_with_PDOupdateTiming(0);
